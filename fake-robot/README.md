# fake-robot

Імітатор робота: підключається до `/robot` так само, як справжній, логує команди і шле фейкову телеметрію. Реалізується на етапі 7.

## Запуск

```bash
cp .env.example .env
uv run main.py
```

## Змінні середовища

| Змінна | Опис |
|---|---|
| `API_WS_URL` | WebSocket `/robot` на api |
| `ROBOT_ID` | ідентифікатор робота |
