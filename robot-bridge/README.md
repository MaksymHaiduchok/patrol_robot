# robot-bridge

Міст між api і мобільною платформою LEGO Technic Audi RS Q e-tron (42160) з Technic Hub (Control+). Працює на Маку: підключається до api як робот через WebSocket `/robot`, а до хаба — по Bluetooth LE через [node-poweredup](https://github.com/nathankellenicki/node-poweredup). Node.js + TypeScript.

## Встановлення і запуск

```bash
cp .env.example .env
pnpm install
pnpm start
```

Під час підключення міст калібрує кермо: повертає його до лівого й правого упору й ставить посередині (так само робить застосунок Control+). Хаб увімкнути кнопкою (має блимати). При першому запуску macOS попросить дати терміналу доступ до Bluetooth (System Settings → Privacy & Security → Bluetooth).

`pnpm probe` — діагностика: знаходить хаб, показує пристрої на портах A–D і по черзі крутить кожен мотор на 30% 1 с.

`pnpm check` — покрокова перевірка з налаштуваннями з `.env`: кермо вліво/вправо/прямо, хід вперед/назад, повороти, потужність 20–100% і кроки `hide`. Перед кожним кроком пише, що має статися, і чекає Enter; після кроку показує, на скільки градусів провернувся кожен ходовий мотор (і °/с) та поточний кут керма.

## Порти моделі 42160

| Порт | Мотор | Роль |
|---|---|---|
| A | Technic L | задні колеса |
| B | Technic L | передні колеса |
| C | — | — |
| D | Technic L | кермо |

## Поведінка

- Хід і кермо незалежні. `move forward/backward` — лише хід ±`speed`% (`speed: 0` — гальмо), кермо не змінюється. `steer left/right/center` — лише кермо: у бік на `STEER_LIMIT_PERCENT`% від повного вивороту або в центр. `move left/right` і `turn left/right` — те саме, що `steer` у той бік.
- `stop` — гальмо на ходових, кермо прямо. `alert` — те саме і стан `ALERT`; `resume` повертає стан, що був до `alert`.
- `hide` — маневр за часом: назад → поворот → вперед, потім стоп і стан `ALERT`. Будь-яка інша команда руху, `stop`, `alert` або watchdog його перериває.
- `set_home` / `return_home` — запис шляху від точки дому й повернення тим самим шляхом. Кожні 20 мс міст записує точку «лічильник коліс (середнє A і B) + реальний кут керма з енкодера». `return_home` їде записаними точками у зворотному порядку без зупинок і по ходу виставляє кермо так, як воно стояло в цьому місці (з випередженням `RETURN_STEER_LOOKAHEAD_DEGREES`). Зупиняється лише там, де під час запису змінювався напрям руху, і вдома; ціль кожного прогону — абсолютне значення лічильника, тож перескок не накопичується. Записується будь-який рух — ручний, `hide`, повернення; перерване повернення зберігає недопройдений шлях; якщо колеса не крутяться `RETURN_STALL_MS` — зупинка; втрата зв'язку з хабом скидає дім. Точність падає з прослизанням коліс і люфтом керма.
- Зупиняти міст — **Ctrl+C** (зупиняє мотори). **Ctrl+Z** лише призупиняє процес: мотори лишаються з останньою командою, а watchdog моста теж стоїть.
- `servo` не підтримується (немає поворотної голови). Датчика відстані немає, тому `distance_cm` у телеметрії — `null`, а `PATROL` не рухає машину сам.
- Watchdog: немає `ping` від api довше `WATCHDOG_SECONDS` → мотори зупиняються.
- Команди моторам ідуть напряму в хаб («виконати одразу, без підтвердження»), а не через чергу `node-poweredup`: її черга застрягає, якщо загубилось підтвердження, і тоді мотор не зупиняється.
- Втрата зв'язку з хабом → `hub: "offline"` у телеметрії, команди руху ігноруються, міст шукає хаб знову.

## Змінні середовища

| Змінна | Опис |
|---|---|
| `API_WS_URL` | WebSocket `/robot` на api |
| `ROBOT_ID` | ідентифікатор робота |
| `DRIVE_PORTS` | порти ходових моторів через кому |
| `DRIVE_INVERTED_PORTS` | ходові порти, які треба крутити в протилежний бік, щоб «вперед» було вперед |
| `STEER_PORT` | порт мотора керма |
| `STEER_INVERTED` | `true`, якщо `left` повертає вправо |
| `STEER_LIMIT_PERCENT` | на скільки % від повного вивороту повертати кермо (100 — до упору) |
| `STEER_SPEED` | швидкість мотора керма, % |
| `STEER_CALIBRATION_POWER` | потужність, з якою кермо шукає упори під час калібрування, % |
| `WATCHDOG_SECONDS` | стоп, якщо довше немає `ping` від api |
| `TELEMETRY_INTERVAL_MS` | період телеметрії |
| `HIDE_BACK_SPEED`, `HIDE_BACK_MS` | hide: їхати назад |
| `HIDE_TURN_SIDE`, `HIDE_TURN_SPEED`, `HIDE_TURN_MS` | hide: поворот (`left`/`right`) з ходом вперед |
| `HIDE_FORWARD_SPEED`, `HIDE_FORWARD_MS` | hide: їхати прямо вперед |
| `RETURN_SPEED`, `RETURN_SLOW_SPEED` | повернення додому: швидкість і швидкість наприкінці прогону, % |
| `RETURN_SLOW_ZONE_DEGREES` | за скільки градусів коліс до кінця прогону сповільнюватись |
| `RETURN_STEER_TIMEOUT_MS` | скільки максимум чекати, поки кермо стане в потрібний кут перед початком прогону |
| `RETURN_TOLERANCE_DEGREES` | допустима похибка в кінці прогону; більша — машинка підтягується на малій швидкості (до 2 спроб) |
| `RETURN_STEER_LOOKAHEAD_DEGREES` | на скільки градусів коліс наперед повертати кермо — компенсує запізнення мотора керма |
| `RETURN_STALL_MS` | зупинка, якщо колеса стільки часу не крутяться |
